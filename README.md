# Cosmology with a non-minimally coupled scalar field to gravity

Code accompanying the Bachelor's thesis (Treball de Fi de Grau) of
**Guillem Duran Ayala**, Universitat de Barcelona, June 2026.

Advisor: Dr. Adrià Gómez-Valent (ICCUB).

## Overview

Numerical reconstruction of the Lagrangian functions $F(\phi)$ and
$U(\phi)$ of a scalar-tensor theory with non-minimal coupling, from the
CPL parametrization of dark energy.
Includes the methodology of Efstratiou et al. (2025) for the dynamic
$U(\phi)$ case.
